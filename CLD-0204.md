# CLD-0204: Internal port sweep outside scan window: 203.0.113.44

Engagement: Cloudora · Shift 1 · 2026-09-25
Verdict: False positive · Severity (my rating): Low (reported Medium)
QA review: Excellent

## Alert
A TCP sweep alert fired, from LDN-SCAN-01, between 23:00 and 03:00

## Hypothesis
if malicious, an attacker is running reconnaissance using the vulnerability scanners address. If benign, the schedule had changed to be taken place between the Sunday 23:00 and 03:00 Monday.

## Evidence checked
The handover report says the weekly vulnerability scan was moved to Sunday 23:00 to Monday 03:00 this week only, the alert fired says the scan happened at 23:30 until just after 1:00 into monday, so it happened between the window that was announced in the handover.

## Action
Closed as false positive

## Justification
The host is a known host, the traffic pattern matches there are no data transfers, the scan took place in the documented window
