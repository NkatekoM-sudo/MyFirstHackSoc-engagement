# CLD-0242: Anonymous sharing link created: Payroll-Live library

Engagement: Cloudora · Shift 11 · 2026-10-27
Verdict: True positive · Severity (my rating): Medium (reported Medium)
QA review: Satisfactory

## Alert
An anonymous access link was shared with the scope 'anyone can with the link, no sign in required edit', this was created on the folder payroll -Live/Mapping, at 22:47 UTC by IT-admins@cloudora.io

## Hypothesis
if malicious, an operator will be able to look at the payrol-live files and edit them, if benign, the link created by the administrator for anyone who has authorization to view the files.

## Evidence checked
Alert: policy shows that the Tenant policy is for tenants to read the files for 30 days only, but this links scope requires no sign in, it is editable, meaning the payroll files can be changed and it does not expire.
Helpdesk: does not show any ticket about the sharing link nor its scope. the IT-admins last helpesk log (HD-5311), was at 15:05
Sharing audit week 3: This link was made anonymous and outside of the working hours targeting the payroll-Live.
Making it editable with no expiry date was unnecessary, the link should required sign in access and it must have an expiry date because right now it is compromising the integrity



## Action
Closed at true positive, because anyone not authorized receives this link they will be able to make changes to the payroll files moved
